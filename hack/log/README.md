# Logs

One file per person: `hack/log/<name>.md`. One line per thing a teammate could trip over, newest last. Each person writes only their own file, so it never conflicts.

    14:05 decided: uploads are capped at 10 MB
    14:20 stand-in: fake scoring in slices/review/fake-score.ts until umar's scorer lands
    14:40 shared: added `status` to the reports table
    15:10 parked: 040-email, the mail service rejects the free tier

Write a line when you:

- make a decision a teammate might have made differently,
- leave a stand-in for something another slice owns,
- add to or change the shared core,
- park a task.

Nobody has to read the logs before working. `/board`, the freeze and the pitch read them.
