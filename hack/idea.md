# The idea

`/kickoff` fills this in, or `/shape` when the team picked the idea without it.

## The event

- Build window: see `hack/clock.env`
- Themes: Web-e-Thon, Technoverse 5.0 (COMSATS Lahore): a secure examination management system for institutions
- Deliverables: a deployed web app, a Git repo with history, a README with test credentials for every role and the innovation write-up; 15-minute live demo
- Rules that limit us: no required feature may depend on a paid API or service; fictional data; no commits after 20:00

## Judging criteria

The organisers' own (100 marks):

1. **Core functionality (30).** The full exam workflow, complete and correct.
2. **Technical quality and reliability (20).** Architecture, database design, security, validation, data integrity, failure handling.
3. **UI/UX and product design (20).** Intuitive, accessible, responsive.
4. **Secondary features (15).** All eight, working and integrated.
5. **Open innovation (15).** Problem understanding, originality, practicality, effectiveness.

## The chosen idea

- **The person:** Ayesha, a student in Lahore with load-shedding twice a day, and Kamran, the lecturer setting her exam.
- **The pain:** outages cost answers and time; wrong answer keys cost marks that only a paid recount can recover.
- **What we build:** Imtihaan, an exam platform (super admin → institutions → admins, examiners, candidates) where answers survive outages and wrong keys are caught before results go out.
- **The demo moment:** the network goes off mid-exam, she keeps answering, and everything syncs; later the Key Doctor catches the wrong key on Q7 and regrades all 30 papers.
- **Why it scores:** every core feature works live, and each innovation answers a named Pakistani incident without a camera or paid AI.

## The risk

- **Most likely to sink it:** scope; the core lifecycle across two slices must be finished before any extra.
- **The fallback if it is not working by mid-afternoon:** drop extras entirely; demo the core lifecycle plus the offline moment and the Key Doctor.
